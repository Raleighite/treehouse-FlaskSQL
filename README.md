# Treehouse — Flask with SQL

Learning project from the Treehouse *Flask with SQLAlchemy* course.

A simple pet management app built with Flask and SQLAlchemy.

## Stack

- Python / Flask
- SQLAlchemy ORM
- Jinja2 templates

## Running

```bash
pip install -r requirements.txt
python app.py
```
